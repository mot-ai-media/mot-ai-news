# DESIGN DECISION TREE(ゆとなみ社から抽出)

単なるスタイルガイドではなく、「なぜその見た目になったか」の因果連鎖を再構成する。

```
CONTENT
  実在する10軒の銭湯 + 代表個人 + 会社としての活動(採用/コンサル/物販)
    ↓
CONTENT IMPORTANCE
  「銭湯そのものの存続」が最重要。会社の実績PRは二の次。
    ↓
VISUAL HIERARCHY
  個別銭湯の固有名・実写 > 会社としての説明文
    ↓
LAYOUT
  数えられる実体(銭湯)だけをグリッド化。それ以外は1本道の帯。
  → 「グリッドにするかどうか」はコンテンツの性質(離散的で対等な実体か)で決まっている。
    ↓
TYPOGRAPHY
  見出しは名詞のみ、装飾的なコピーを乗せない
  → 誇張しなくても「実在」が説得力を持つコンテンツだから成立する。
    ↓
SPACING
  セクション数を絞る(約7)ことで、1つ1つの帯に軽い滞在時間を作る
    ↓
IMAGE
  実写のみ・ストック素材なし
  → 「本当にやっている」ことの証拠として画像を使う。装飾ではなく証拠。
    ↓
INTERACTION
  過剰な演出の痕跡なし。クリックして個別銭湯情報に辿り着ければ十分。
    ↓
FINAL COMPOSITION
  「儲かってそうな会社サイト」ではなく「本当に稼働している現場の目次」に見える。
```

## この木から取り出せる汎用アルゴリズム(どのブランドにも使える形)

```
1. コンテンツの実体を洗い出す(数えられる実体か、単一の主張か、進行中の物語か)
2. 実体ごとの重要度を決める(会社の都合ではなく、読者にとっての重要度)
3. 「離散的で対等な実体が複数ある」場合のみグリッドを検討する
   → そうでなければ1本道・非対称レイアウトを優先する
4. 見出しは機能を素っ気なく名乗る。誇張コピーは実績が伴わない限り使わない
5. 画像は「証拠」として使えるものだけを採用する。証拠がなければ画像を置かない
6. セクション数を絞り、1帯ごとに読者が一呼吸おける密度にする
7. 装飾(角丸・影・グラデーション・アイコン)は、成立を助けていない限り足さない
```

MOTへの適用は `04_VISUAL_LANGUAGE.md` 以降で行う。
