# YUTONAMISHA-SPECIFIC(MOTに移植してはいけないもの)

ゆとなみ社だからこそ成立している固有表現。これらをそのままMOTに持ち込むと
「コピーサイト」になるため、明確に禁止する。

- 銭湯の夜景写真・暖色照明の質感 → MOTはAI/テクノロジーメディアであり、
  この写真的世界観を持ち込む理由がない。
- 円形の企業ロゴマーク自体のデザイン。
- 「10軒の実店舗」を前提にしたグリッド構造 → MOT NAGANOも含め、MOT側には
  現時点でこの数の実体的拠点がない。中身が無いのに形だけ真似ると
  「テンプレ感」の温床になる。
- 代表個人(湊三次郎氏)を前面に出す、創業者ストーリー駆動の語り口 →
  MOTは特定個人の物語を主軸にしたブランドではない。
- 銭湯・継業という業界固有の語彙・文脈。
- 「廃業寸前から10軒経営へ」のような、実績年表を大きく見せる構成 →
  MOTには同種の実績が(現時点で)存在しない。実績のねつ造は禁止事項でもある。

これらは「ゆとなみ社の物語だから機能している」要素であり、原則ではなく表現。
`UNIVERSAL_PRINCIPLES.md` にある抽象原則だけをMOTに翻訳する。
