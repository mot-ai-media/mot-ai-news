# 02. UX PRINCIPLES

## 読者の理想的な滞在フロー

1. **最初に見るもの**:今日いちばん重要な1本(HERO)。他の記事と明確に
   別格の大きさ・扱いであるべき(現状は`_render_hero`が実装済みだが、
   カードのビジュアル言語自体は一覧の`.card`とほぼ地続き)。
2. **次に見るもの**:今日のダイジェスト、または話題のテーマ。
3. **興味を持つもの**:自分の理解度(やさしい/テクニカル)に合う記事。
4. **クリックする場所**:見出し・サムネイルではなく「もっと知りたい」と
   思わせる要約1行。
5. **記事内での滞在**:TL;DR→詳細→MOTの見解→出典、の順で「読む前に一呼吸」
   できる構造を保つ。

## MOTが導きたい心理状態

「速く大量に情報を消費させる」のではなく、
**「この1本は信頼して読んでいい」と思わせてから読ませる**。

具体的には:
- 出典・更新時刻・難易度を本文の前に必ず見せる(現状の`trust-strip`は
  この思想に合致しているので維持・強化する)
- 速報色(breaking)は本当に速報の記事だけに使い、通常記事には使わない
- 一覧では「今日読むべき1本」と「その他」を視覚的に明確に分ける
