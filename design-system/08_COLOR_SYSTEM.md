# 08. COLOR SYSTEM

## 現状の良い点(壊さない)

`build_site.py`の`:root`コメントは既に正しい思想を書いている:

> 意味を持たせたアクセントカラー(Von Restorff効果: 本当に重要な箇所だけに
> 使う。通常のUIはグレー/紺の落ち着いた色で統一し、下記は速報・急上昇・人気・
> 肯定・主要導線にのみ使用)

この思想自体はMOTらしく、変更しない。問題は**運用が思想通りになっていない**こと
(バッジやフィルタボタンなど、常時表示される装飾にまで意味色が広がっている)。

## 運用ルールの厳格化

- `--mot-breaking` は「実際に速報性のある記事」だけに使う。NEWバッジのように
  **生成後5時間以内すべて**に機械的に付けるのは意味の希釈にあたる。
  → 新着であることと速報であることを分離し、新着は控えめなグレー系にする。
- `--mot-trending` / `--mot-popular` も、1画面につき同時に何個も光らせない。
  複数使うなら、優先順位をつけて1つだけ強調する。
- `--mot-primary`(青)はリンク・主要導線のみ。装飾ボーダーに多用しない。
- ベースは`--mot-border` / `--mot-text-secondary`の落ち着いたグレー系のみで
  UIの9割を構成する。

## サムネイル代替色の廃止

`FALLBACK_GRADIENTS`(紫/紺/青緑の135度グラデーション6色)は、AI生成デザインの
典型例そのものであり廃止する。代替は`09_IMAGE_DIRECTION.md`を参照。

## ダークモード

既存の`:root[data-theme="dark"]`によるトークン上書き構造は健全な設計。
新しいトークンを追加する際も、必ずライト/ダーク両方の値をセットで定義する。
