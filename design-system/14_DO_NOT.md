# 14. DO NOT LIST

MOTがAI生成サイトっぽくなる直接原因。例外はMOTの思想に合う場合のみ認める。

| 禁止 | 理由 | 例外 |
|---|---|---|
| 紫/青系の装飾グラデーション | `FALLBACK_GRADIENTS`が典型例。AI生成デザイン最頻出パターン | なし。`09_IMAGE_DIRECTION.md`のタイポグラフィ処理に置き換える |
| 全カード均一の角丸+影 | 重要度の差を消す | `major`記事のみ`--mot-shadow-major`を許可 |
| バッジ/ラベルの丸ピル濫用 | 通知バッジのようなSaaS感 | フィルタの選択状態(操作可能ボタン)のみ`--mot-radius-full`許可 |
| 常時複数の意味色が点灯 | Von Restorff効果が消耗する | 1画面1強調が原則。速報時のみ複数許容 |
| カードのホバー浮き上がり演出 | 汎用SaaSダッシュボードの典型 | なし |
| スクロール連動のフェードイン演出全要素適用 | 意味のない動きの濫用 | 無限スクロールの新規読み込みのみ許可 |
| 装飾目的のアイコン追加 | 情報不足をアイコンで埋める典型パターン | 機能アイコン(検索・テーマ切替・メニュー)のみ許可 |
| font-sizeの場当たり的な追加 | スケール崩壊 | `05_TYPOGRAPHY.md`の7段階で足りない場合のみ、要相談の上で追加 |
| ダミー実績・誇張された数値 | 事実の捏造(親CLAUDE.mdの大原則) | 例外なし |
| 「未来的」「革新的」「次世代」等の紋切り型コピー | ブランドの言葉を薄める | 例外なし |

## 「禁止のための禁止」にしない

上記はすべて監査で実際に確認された症状に基づく。新しい禁止項目を追加する際は
「なぜMOTの思想に合わないのか」を一行で言えることを条件にする。
