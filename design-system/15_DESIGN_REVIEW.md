# 15. DESIGN REVIEW CHECKLIST

Claude Code(またはその他の実装者)がMOTのUIを変更する際、コミット前に
必ず以下を自問する。

- [ ] これはMOTにしか見えないか?(汎用テンプレートの流用に見えないか)
- [ ] generic SaaSダッシュボードに見えないか?
- [ ] 記事の重要度がレイアウトの違いとして伝わるか?(色バッジだけに頼っていないか)
- [ ] font-sizeは`05_TYPOGRAPHY.md`の7段階の中から選んだか?
- [ ] border-radiusは`--mot-radius-sm/md/full`のどれかか?
- [ ] 新しいグラデーション・装飾色を追加していないか?
- [ ] 画像がない箇所に、証拠のない装飾(ランダムグラデーション等)を
      置いていないか?
- [ ] アニメーションは「意味の切り替わり」のためだけに使われているか?
- [ ] whitespaceは4段階の`--mot-space-*`のどれかに沿っているか?
- [ ] モバイル幅でも「今日いちばん重要な記事」が一目でわかるか?
- [ ] 出典・更新日・難易度という誠実さの情報が、本文より前に見えるか?
- [ ] 既存記事(過去に生成済みのarticles/*.html)を壊していないか?
      (`regenerate_all()`を実行する場合は影響範囲を事前に説明したか)
- [ ] 既視感(「どこかで見たことがある」感)がないか?
