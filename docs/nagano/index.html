まだ、誰も書いていない長野がある。

MOT NAGANOは、長野の人と仕事を、ひとつずつ訪ねて記録していくプロジェクトです。まだ始まったばかりです。

今ここにあるのは、まだ数えるほどの言葉です。

長野の誰かに会い、話を聞き、その場所に立つ。それを一つずつ、ここに置いていきます。急いで増やすつもりはありません。

これから見にいくもの

  • 人長野で暮らし、働いている人の話。
  • 仕事まだ小さくても、続いている仕事の話。
  • 場所その仕事や暮らしが生まれている場所の話。
  • 挑戦始まったばかりの、これからの話。
  • 暮らし特別ではない、日々の話。
