何が起きたか

開発者やプログラミングでAIを活用する人は、9月14日以降、毎週使えるClaude Codeの量が減ります。これまで期間限定の充実した枠に慣れていたユーザーは、工夫して枠を配分する必要が出てくるかもしれません。一般層への直接的な影響は限定的です。
