AIエージェント、ついに犯罪に本格活用。韓国銀行襲撃の黒幕は「26歳」

🟢 やさしい SOURCEITmedia AI＋ 最新記事一覧 UPDATED2026-10-09 22:01

MOT ANALYSIS

TL;DR 生成AIを使った自動攻撃ツールで韓国の複数銀行が被害を受け、攻撃者は利用記録から26歳の中国在住者と推定される。1人のハッカーがAIで大規模攻撃を短期間に実行できる時代が来た。

何が起きたか

韓国の金融機関9行以上が9月末から相次いでサイバー攻撃を受けました。セキュリティ企業CrowdStrikeが攻撃インフラを調査したところ、攻撃者がClaudeなどの生成AIと中国製の侵入テストツール「ARTEX」を組み合わせて悪用していたことが判明。さらにサーバに放置されていたClaudeの利用記録から、攻撃者が26歳で中国広東省在住という個人情報まで発見されました。

なぜ重要か

これまでのハッカーによる攻撃は限定的でしたが、生成AIが使えるようになったことで、1人の攻撃者が短期間に多数の標的を狙える時代に突入しました。AIが攻撃を自動化・高速化させるツールとして機能し始めたことは、サイバーセキュリティの脅威が質的に変わったことを意味します。

あなたへの影響

金融機関の顧客データが盗まれるリスクが増加します。また、攻撃に使われたAIツール（生成AIやARTEXなど）の悪用に対する社会的な警戒感が高まれば、AIツールの利用に規制や認証が強化される可能性があります。一般ユーザーも金融取引時のセキュリティ確保がより重要になってくるでしょう。

MOT読者が知っておくべき理由

ChatGPTやClaudeなどの便利な生成AIが、実は高度な犯罪にも使われている現実。自分の預金や個人情報を守るために、どういう脅威が存在するかを知ることは急務です。

知らないと生まれる差

攻撃者がAIを使いこなすほど、防御側も対抗手段を用意しなければ被害が拡大する一方です。セキュリティ人材や対策技術が追いつかなければ、今後さらに大規模な金融被害が生じるおそれがあります。

これを知ることで得られるチャンス

企業はこのような事例から学び、AIツールの監視・ログ管理、従業員への検収指導を強化できます。また攻撃者が痕跡を残すことで身元特定が進む仕組みもあり、AI時代のセキュリティ対策とフォレンジック技術の向上につながる可能性があります。

MOTの見解

重要なのは、AIそのものが「悪い」のではなく、使い手の意図次第だということです。同じClaudeでも、セキュリティ研究の履歴書作成に使うか、犯罪のための市場調査に使うかで全く意味が変わります。また攻撃者がAIの利用記録に個人情報を残していたことは、便利さと追跡可能性が両面になっていることも示唆しています。

今後の注目ポイント

今後のポイントは、各国がARTEXなどの侵入テストツールや生成AIの悪用防止にどう規制・対策するかです。また同様の手口を使う他の犯罪集団が出現するか、セキュリティ業界がAI時代の防御技術をどこまで進化させるかも注視する必要があります。
