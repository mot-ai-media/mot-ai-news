Microsoft 365ファミリープランついにAI機能を共有可能に。これまでは主契約者だけの特権

🟢 やさしい SOURCEThe Verge UPDATED2026-10-09 16:28

MOT ANALYSIS

TL;DR Microsoft 365 Familyの全家族メンバーがAI機能「Copilot」を共有利用可能になる。主契約者だけの特権が解除される大きな変更。

何が起きたか

マイクロソフトが、サブスクリプションサービス「Microsoft 365 Family」の仕様を変更します。これまでOfficeやOneDrive（クラウドストレージ）は家族内で共有できていましたが、AIアシスタント「Copilot」などAI機能は主契約者のみの利用に制限されていました。その制限が解除され、家族全員がAI機能を使えるようになります。

海外ではどう報道されているか

米テック専門媒体「The Verge」が報道。Microsoftが昨年AI機能をMicrosoft 365に統合した際、ファミリープランでは主契約者のみのアクセスに限定していた経緯を指摘。今回の変更は、ファミリー・プレミアムプラン両方に適用される予定。ただし家族全体のOneDrive容量は統一される。

なぜ重要か

ここ数年、企業はAIを有料サービスの目玉機能として位置付けています。Microsoftも同様にCopilotを上位サービス化していました。しかし競合他社の動向や市場からの圧力を背景に、家族共有という一般的な利用形態に対応する必要が生じた。これはAI機能の『素人向け』化を示す転機です。

日本への影響

日本でもMicrosoft 365は広く利用されており、家族・小規模企業が多く契約しています。会議資料の自動作成やメール返信サジェスト、文章の添削など、AI機能の価値を複数人で活用できることで、家庭向けサブスクの魅力が高まる可能性があります。ただしOneDrive容量の統一化は、家族内でストレージ争奪戦を招く可能性も考えられます。

今後どうなる

マイクロソフトがAI機能の共有化に踏み切ったことで、他企業でも家族プランの再構成が加速する可能性があります。今後の注目点は、GoogleやAppleなど競合企業の対応と、AIクレジット・使用量上限の仕組みが家族内でどう管理されるかです。

MOTの見解

大手テック企業がAI機能を『プレミアム限定』から『標準装備』へシフトさせている。AIの民主化は既に始まっている。

今後の注目ポイント

Microsoft 365 Familyプランの価格変更があるか。Googleの同等サービスの対応。日本での実施時期と利用可能機能の詳細。

Q. Copilotって何？

Q. OneDriveが2TBの共有プール化で、個人の容量はどうなる？

家族全体で2TBの枠を共有する方式に変わります。個別の容量上限は明らかにされていません。
