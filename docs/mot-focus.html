Chrome Extension · MOTが作るプロダクト

MOT Focus

散らかったブラウザを片付けて、今やることに集中する。

開いているタブが多すぎて集中できない人のためのChrome拡張機能。

Chrome Web Storeで使ってみる ↗ Chrome ウェブストアの MOT Focus ページに移動します

FEATURES

できること

集中するタブだけを残す

5 / 15 / 25 / 45分、またはカスタム時間を選択。今やることに関係のないタブを一時的に片付けて、今使うタブだけが残る状態を作れます。

タブは「PARK」に退避

選ばなかったタブは削除されません。安全にPARKへ退避し、集中が終わったらいつでも復元できます。

強制的にブロックしない

集中中に別のタブを開いても強制的にブロックはしません。そっと集中に戻れるよう、そのつど導線を出します。

元のブラウザ環境を復元

集中終了後、元のウィンドウ・タブの順序・タブグループを可能な限りそのまま復元します。

タブを整理

タブを「今やってる」「調べもの」「あとで」「不要かも」に分類し、頭の中と同じ形でブラウザを整理できます。

AIを使わずタブを整理

「しばらく開いていない」「同じ作業で使っていそう」といったタブを、ローカルのルールだけで見つけて提案します。

集中時間を振り返る

今日・今週・今月、どれくらい集中できたかを振り返ることができます。

PRIVACY

安心して使えること

  • ログイン不要
  • 課金不要
  • 外部送信なし
  • データは端末内で完結
  • タブを自動削除しない
  • AI不使用

MOT Focusは、タブの情報を外部サーバーに送らずローカルだけで処理する設計にしています。Chrome Web Storeの公開情報に基づく内容です。
